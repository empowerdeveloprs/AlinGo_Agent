# AlinGo Agent

Silent background agent for AlinGo Control Server.

## Build

Push to GitHub, then Actions → "Build AlinGo Agent APK" → Run workflow.

## Install

Download APK from Actions artifacts, install on Android device.

## Setup

1. Open AlinGo Control Server dashboard
2. Go to "Agent Setup" 
3. Generate setup link for device
4. Send link + APK to data collector
5. Data collector installs APK, taps link
6. Agent starts silently in background
